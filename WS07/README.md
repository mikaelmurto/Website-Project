Tämä websivusto on osa Laurean opintojaksoa websivuston kehittämisestä.

Se on yksinkertainen HTML sivu jossa on käytetty bootstrapin tarjoamaan layouttia.

Sivuston aihe oli vapaa mutta vaatimuksena oli että se sisältää vähintään neljä eri sivua ja kertoo jostain oikeasta asiasta. Lisäksi plussaksi katsottiin se että käyttää HTML, CSS ja Bootstrapin mahdollistamia ominaisuuksia monipuolisesti.

Oma sivustoni kertoo muutamasta intohimoharrastuksestani.

Tässä on tekoälyn yhteenveto readme.md tiedostoksi

# WS07 – Superin harrastukset

Henkilökohtainen harrastussivusto, joka on toteutettu osana Website Project -kurssia. Sivusto esittelee Mikael "Superi" Murron harrastuksia ja kiinnostuksen kohteita.

## Sivuston rakenne

| Tiedosto | Sisältö |
|----------|---------|
| `index.html` | Etusivu – lyhyt esittely harrastuksista |
| `ha.html` | Kotiautomaatio-sivu |
| `olut.html` | Olut ja kotiolutprojektit |
| `youtube.html` | YouTube-kanava, editointi ja laitekuvaukset |
| `styles/style1.css` | Sivuston tyylitiedosto |
| `img/` | Kuvia projekteista ja harrastuksista |

## Teknologiat

- **HTML5** – sivujen rakenne
- **Bootstrap 5.3** – responsiivinen ulkoasu ja komponentit
- **CSS** – mukautettu tyylitiedosto (`styles/style1.css`)

## Sivujen sisältö

### Etusivu (`index.html`)
Lyhyt esittely tekijästä sekä taulukko harrastuksista. Sisältää kuvakarusellin projekteista ja linkit LinkedIn-, YouTube- ja Untappd-profiileihin.

### Kotiautomaatio (`ha.html`)
Kuvaus kotiautomaatioprojekteista, tilastoja toteutuksesta sekä linkkejä aiheeseen liittyviin resursseihin.

### Olut (`olut.html`)
Tietoa oluenkulttuurista, kotioluenpanosta ja keezerin rakentamisesta. Sisältää Untappd TOP 5 -listan sekä kuvia olutprojekteista.

### YouTube (`youtube.html`)
Kuvaus YouTube-kanavasta, editointikoneen spesifikaatiot, NAS- ja verkkoympäristö sekä esimerkkiprojekteja.

## Kuvat

Kansio `img/` sisältää sivustolla käytetyt kuvat projekteista, harrastuksista ja profiilikuvan. Yhteensä 17 valokuvaa + muita grafiikkatiedostoja.
